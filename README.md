## 🚀 Featured Projects

### 🎖️ Military Asset Management System
![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)

A full-stack app to track military equipment across bases: purchases, transfers, personnel assignments and expenditures.

- 🗄️ **9-table PostgreSQL schema** (JPA/Hibernate) with primary/foreign keys plus unique and not-null constraints
- 🔁 **`@Transactional` services** so stock updates and transaction records save atomically; transfers are rejected if the quantity exceeds available stock
- 📊 **Dashboard** with purchases, transfers in/out, assigned, expended, net movement and closing balance, filterable by base and equipment type
- 🔐 **Spring Security + JWT + BCrypt**, with an **audit log** of user, action and timestamp for every create, update and delete
